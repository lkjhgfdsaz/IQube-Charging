💡 Smart Tips

  • Eco Mode full-range reference: 115 KM.
  • Power Mode full-range reference: 76 KM.
  • Battery percentage is the same in Eco and Power mode.
  • Eco and Power mode change estimated range, not battery percentage.
  • Scheduled charging occurs after the selected day’s ride.
  • Charging cost includes the selected charging-efficiency loss.
  • Use actual daily distance values for more accurate predictions.
