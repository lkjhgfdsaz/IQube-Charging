💡 Smart Tips

  • Eco Mode full-range reference: 115 KM.
  • Power Mode full-range reference: 76 KM.
  • Battery percentage is common to both riding modes.
  • Eco/Power mode changes estimated range, not battery percentage.
  • Routine charging is applied after the selected day’s ride.
  • Cost includes the charging efficiency value entered above.
  • Use the cell-balancing reminder for an occasional 100% charge.
  • Use actual daily riding distance for the best forecast.
